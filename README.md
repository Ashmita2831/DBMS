🛒 Online Shopping System (DBMS Project)
📘 Overview
This project designs a Relational Database Management System (RDBMS) for an Online Shopping System that manages customers, products, 
categories, orders, and transactions. It demonstrates real-world e-commerce operations like product purchase and payment processing using SQL.

🎯 Aim
To build a normalized and efficient database system ensuring data integrity and smooth workflow for an online shopping environment.

🧭 Objectives
Model entities and relationships using an E–R Diagram.
Convert to Relational Schema and normalize up to 3NF.
Create tables with constraints (PK, FK, CHECK, UNIQUE).
Perform DDL, DML, and SQL queries using SELECT, WHERE, GROUP BY, HAVING, and JOIN.

🛠 Tools & Technologies
MySQL / XAMPP / phpMyAdmin
SQL Language
Windows OS

📊 Features
Manage customer and product data
Track orders and payments
Apply constraints for data integrity
Demonstrate multiple SQL operations
